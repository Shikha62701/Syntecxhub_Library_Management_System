# 📚 Library Management System

A console-based **Library Management System developed in Java** as part of the Syntecxhub Java Programming Internship.

## 🚀 Features

* Add new books
* Remove books
* Search books by title
* View all books
* Issue books
* Return books
* Input validation
* Error handling
* Book availability status

## 🛠️ Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* Scanner
* Exception Handling

## ▶️ How to Run

### 1. Compile the Java files

```bash
javac *.java
```

### 2. Run the program

```bash
java Main
```
